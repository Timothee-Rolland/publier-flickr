PUBLIER SUR FLICKR — installation

1. Télécharger le zip :
   https://github.com/Timothee-Rolland/publier-flickr/releases/latest/download/Publier-sur-Flickr.zip
   puis double-cliquer dessus pour le décompresser.

2. (Conseillé) Glisser « Publier sur Flickr » dans le dossier Applications,
   puis dans le Dock pour l'avoir sous la main.

3. Double-cliquer sur l'app. Rien à installer : tout est inclus.

   La toute première fois seulement, macOS bloque l'ouverture
   (« Apple ne peut pas vérifier… ») :
   - macOS 15 et plus : cliquer « OK », puis Réglages Système →
     Confidentialité et sécurité → en bas, « Ouvrir quand même » ;
   - macOS 14 et avant : clic droit sur l'app → Ouvrir → Ouvrir.

4. Au premier lancement, l'app demande la clé et le secret Flickr du groupe
   (à demander au responsable du compte), puis ouvre Flickr dans le navigateur :
   se connecter avec le compte du groupe et cliquer « OK, I'll authorize it ».

C'est tout. Les mises à jour s'installent toutes seules au lancement.

Utilisation : glisser un dossier de photos dans la fenêtre. Un album par sous-dossier.
Les photos sont envoyées en privé par défaut.

Si l'app ne voit pas des photos posées sur le Bureau :
mettre le dossier ailleurs (Images, Documents…).

En cas de problème : envoyer le fichier
~/Library/Application Support/Publier sur Flickr/journal.txt
